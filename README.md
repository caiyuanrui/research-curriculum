# Research Curriculum

系统性的研究学习笔记 — 每日一篇论文，追踪 AI 各领域发展脉络。

🌐 **GitHub Pages**: https://caiyuanrui.github.io/research-curriculum

## 课程结构

| 课程 | 时间 | 描述 |
|------|------|------|
| Agent Course | 周一 | AI Agent 技术路线 |
| OOD Course | 周二 | 分布外检测与泛化 |
| Diffusion Course | 周三 | 扩散模型理论与实践 |
| LLM Systems | 周四 | LLM 系统架构 |
| Lab Reports | 周五 | 前沿实验室报告 |
| Weekly Review | 周六/日 | 跨领域总结 |

## 运行方式

由 Hermes Agent 的 cron 系统自动驱动，每天北京时间 20:00（UTC 12:00）触发。

## 技术栈

- **发布平台**: GitHub Pages + MkDocs Material
- **驱动**: Hermes Agent cron
- **状态管理**: 本地 JSON state 文件
