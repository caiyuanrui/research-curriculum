# Scaling Up Visual and Vision-Language Representation Learning With Noisy Text Supervision (ALIGN)

**Authors:** Chao Jia, Yinfei Yang, Ye Xia, Yi-Ting Chen, Zarana Parekh, Hieu Pham, Quoc V. Le, Yunhsuan Sung, Zhen Li, Tom Duerig
**Year:** 2021 | **Venue:** ICML 2021
**Link:** [https://arxiv.org/abs/2102.05918](https://arxiv.org/abs/2102.05918)

---

## Core Problem

How can we scale visual and vision-language representation learning to billions of image-text pairs without relying on expensive, manually curated datasets? Prior work (CLIP, Conceptual Captions) demonstrated the value of web-sourced data, but CLIP still filtered to ~400M "high-signal" pairs and Conceptual Captions used only 3M carefully cleaned pairs. The question was: **Can extreme scale compensate for extreme data noise?**

## Historical Context

Before 2021, the dominant paradigm for vision-language pretraining was:

1. **Curated multimodal datasets** — MSCOCO (123K images, 5 captions each), Conceptual Captions (3.3M pairs, heavily filtered), Visual Genome — all requiring expensive human annotation or sophisticated filtering pipelines.
2. **Complex multi-task objectives** — Models like UNITER, OSCAR, and ImageBERT used cross-attention transformers trained on Masked Language Modeling + Image-Text Matching + Region Classification, requiring object detectors for region features.
3. **CLIP (Radford et al., 2021)** had just shown that a simple dual-encoder with contrastive loss could work on 400M web pairs, but the dataset was still carefully constructed (openAI did not release it). The community needed to know: *Could this be done with even less curation?*

ALIGN was developed concurrently with CLIP and submitted to arXiv approximately one month before CLIP (Feb vs Mar 2021), though both appeared at ICML 2021. It specifically attacked the **data bottleneck**: the assumption that noisy web data is inferior to curated data for learning visual representations.

## Main Idea

ALIGN (A Large-scale Image and Noisy Text embedding) makes a deliberately provocative claim: **scale can substitute for curation**. Rather than spending engineering effort on cleaning, filtering, or deduplicating web data, simply use more of it — 1.8 billion image-alt-text pairs — and train a straightforward dual-encoder model with a contrastive loss.

The key insight is that web alt-text, despite being noisy (misspellings, irrelevant descriptions, boilerplate), still contains enough signal at the billion-pair scale to learn representations competitive with carefully curated approaches. In fact, ALIGN showed that with only **4x more data** than Conceptual Captions, the noisy data surpassed the clean data in downstream performance — and at full scale (1.8B vs 3M), the gap became enormous.

## Technical Details

**Architecture:**
- **Image encoder:** EfficientNet (variants from B1 to L2), with global pooling and no 1×1 convolution head (unlike CLIP which added a learned projection).
- **Text encoder:** BERT (Mini to Large), using the `[CLS]` token embedding followed by a linear projection to match the image embedding dimension.
- **Fusion:** Simple cosine similarity — no cross-attention, no multi-modal fusion layers.

**Training objective:** Symmetric contrastive loss (InfoNCE-style), normalized softmax over in-batch negatives:

$$
L = -\frac{1}{2N}\sum_{i=1}^{N}\left(\log\frac{\exp(x_i^T y_i / \sigma)}{\sum_j \exp(x_i^T y_j / \sigma)} + \log\frac{\exp(y_i^T x_i / \sigma)}{\sum_j \exp(y_i^T x_j / \sigma)}\right)
$$

where $\sigma$ is a learnable temperature parameter (initialized to 1.0, converging to ~1/64 during training).

**Training scale:**
- Batch size: 16,384 (concatenated across 1,024 TPUv3 cores)
- Embedding dimension: 640 (for largest models)
- Optimizer: LAMB with learning rate warmup

**Dataset construction (1.8B pairs):**
- Source: Alt-text from web images — minimal filtering:
  - Remove pornographic images
  - Remove images with short side < 200px or aspect ratio > 3
  - Remove images with >1,000 associated alt-texts
  - Deduplicate near-duplicates of test set images (embedding-based)
  - Text: discard alt-text shared by >10 images, or with rare tokens, or length < 3 or > 20 unigrams
- Total: 1.8 billion image-text pairs — 4.5× larger than CLIP's 400M, 600× larger than Conceptual Captions

**Key design choices:**
- No image-text matching or masked language modeling heads — pure contrastive learning
- No cross-attention during pretraining — efficiency at scale is paramount
- Simpler data pipeline than CLIP — less aggressive filtering

## Research Takeaway

ALIGN achieved **state-of-the-art results across the board**, validating the "scale beats noise" hypothesis:

**Image-Text Retrieval (zero-shot):**

| Benchmark | Metric | ALIGN | CLIP | Improvement |
|-----------|--------|-------|------|-------------|
| Flickr30K (1K) | i2t R@1 | 88.6 | 88.0 | +0.6 |
| Flickr30K (1K) | t2i R@1 | 75.7 | 68.7 | **+7.0** |
| MSCOCO (5K) | i2t R@1 | 58.6 | 58.4 | +0.2 |
| MSCOCO (5K) | t2i R@1 | 45.6 | 37.8 | **+7.8** |

**Zero-Shot Image Classification (top-1):**

| Dataset | ALIGN (EfficientNet-L2) | CLIP (ViT-L) |
|---------|--------------------------|--------------|
| ImageNet | **76.4%** | 76.2% |
| ImageNet-R | **92.2%** | 88.9% |
| ImageNet-A | **75.8%** | 72.2% |
| ImageNet-V2 | **70.1%** | 70.1% |

**Linear classification (ImageNet, frozen backbone):** 85.5% (ALIGN) vs 85.4% (CLIP ViT-L)

**Fine-tuned ImageNet:** 88.64% using 44% fewer FLOPs than NoisyStudent

**VTAB (19 tasks):** 72.8% — surpassing BiT-L (72.4%)

The most striking finding is the **text-to-image retrieval gap**: ALIGN outperformed CLIP by 7+ points on both Flickr30K and MSCOCO t2i R@1, suggesting that the larger, noisier dataset was especially beneficial for learning robust text embeddings.

### Data scaling ablations

A critical experiment compared ALIGN data against Conceptual Captions at matched sizes:

- With only **4× data** (12M noisy pairs vs 3M clean pairs), ALIGN data already matched or exceeded Conceptual Captions performance.
- At full scale (1.8B), the gap was dramatic — demonstrating a clear **data scaling law** where noise is offset by quantity.

## Influence

ALIGN had a substantial influence on the subsequent development of vision-language models:

1. **Validated the "scale compensates for noise" thesis** — This became a core assumption of the field. Later datasets like LAION-400M and LAION-5B explicitly cited ALIGN's approach to minimal filtering at scale.

2. **Inspired open-source efforts** — The ALIGN-style dual-encoder with EfficientNet became a standard baseline. OpenCLIP and other open-source reproductions built on this architecture.

3. **SigLIP (Zhai et al., 2023)** directly built on ALIGN by improving the loss function (sigmoid loss removes the need for global batch normalization), using a ViT backbone instead of EfficientNet, but keeping the same dual-encoder philosophy.

4. **Influenced retrieval systems** — ALIGN's approach to text-to-image retrieval using simple dual encoders set new SOTA and demonstrated that complex cross-attention was unnecessary for retrieval tasks, influencing the design of later retrieval models.

5. **EfficientNet adoption** — ALIGN was the first major VLM to adopt EfficientNet as the vision backbone, showing it was competitive with ResNet and ViT for multimodal pretraining.

## Modern Perspective

From today's vantage point, ALIGN's contribution looks both prescient and partially superseded:

**What held up well:**
- The "scale > curation" thesis is now universally accepted. The billion-pair web-data paradigm is the standard for VLM pretraining.
- The dual-encoder + contrastive loss architecture remains the backbone of most deployed multimodal retrieval and zero-shot classification systems.
- The focus on efficient inference (EfficientNet, no cross-attention) was ahead of its time — many production systems still use dual encoders for this reason.

**What got superseded:**
- EfficientNet has been largely replaced by Vision Transformers (ViT) in modern VLMs (SigLIP, CLIP ViT variants). ViT scales more gracefully with compute and integrates better with transformer-based text encoders.
- Sigmoid loss (from SigLIP) has replaced the softmax-based contrastive loss, removing the batch-size bottleneck and enabling training on smaller hardware.
- Modern VLMs (LLaVA, InternVL, Qwen-VL) go far beyond dual encoders — they fuse vision features into large language models for open-ended visual reasoning, a task ALIGN-style models cannot do.
- The ALIGN dataset itself was not publicly released, but it directly inspired the public LAION datasets.

**Limitations revealed in hindsight:**
- Dual encoders are fundamentally limited for fine-grained visual reasoning — they align global image and text semantics but cannot localize, count, or compare visual details.
- Pure contrastive learning, even at billion-pair scale, saturates for certain tasks. Modern approaches supplement contrastive objectives with generative or dense matching objectives.
- The "no filtering" approach propagates web biases directly into representations, raising fairness concerns that later work (DataComp, LAION filtering) attempted to address.

## Key Insight to Remember

ALIGN's most important lesson is a **data scaling law**: for multimodal representation learning, data quantity and data quality are directly substitutable — scale can buy you freedom from expensive curation. This principle has been replicated across domains (language modeling, code generation, speech recognition) and remains one of the most robust findings in modern ML: when in doubt, add more data.

The concrete technical contribution — that a simple dual encoder with contrastive loss on noisy web data at 1.8B scale outperforms complex cross-attention models on curated data — set the template for a generation of multimodal models and directly enabled the billion-scale data collection efforts that followed.
